# KinoPoint Film

Сайт камерної творчої кіношколи **KinoPoint Film** (Одеса).

## Технологічний стек

- **React 18** + **TypeScript**
- **Vite** — збірка та локальний сервер
- **Tailwind CSS** — стилізація
- **Radix UI** — компоненти
- **React Router** — маршрутизація

## Запуск локально

```bash
npm install
npm run dev
```

Сайт буде доступний на `http://localhost:5173/`

## Структура проєкту

```
src/
  assets/       — зображення та медіа
  components/   — компоненти (Header, Footer, UI)
  pages/        — сторінки (Index, Acting, Screenwriting, Journalism, Apply, About)
  index.css     — дизайн-система
```
